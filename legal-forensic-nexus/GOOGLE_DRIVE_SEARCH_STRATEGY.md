## 📊 HOW TO USE THESE SEARCHES

### Step 1: Open Google Drive
1. Go to drive.google.com
2. Click the search bar at the top

### Step 2: Use Advanced Search
1. Click the filter icon (looks like sliders)
2. Select "Type" for specific file types
3. Use "Date modified" for time ranges

### Step 3: Document Your Findings
For EACH search that returns results:
1. Take a screenshot of the search results
2. Note the number of files found
3. Open suspicious files and screenshot key pages
4. Check "Version history" on any suspicious files

### Step 4: Priority Files to Open
When you find files, prioritize opening:
- Anything with "HMIA" in the name
- Documents from August 2019
- Any file mentioning "XO29MP"
